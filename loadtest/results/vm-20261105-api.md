## Postgres paused (`docker pause`), a request for an uncached experiment

```
timeout on the pool only:     000 after 20.00 s (no answer, curl gave up)
timeout on pool and query:    500 after 5.00 s  (the fix)
database back:                200 after 0.00 s
```

The first attempt only limited the wait for a pool connection. The request
got an open connection and then waited for the paused database with no limit,
so `DB_TIMEOUT` covers the query too.
